----¿Que es Velvet & Blade?----
 
Aplicación móvil híbrida desarrollada con Ionic Framework, JavaScript y Capacitor, orientada a la gestión de citas y a la mejora de la experiencia del cliente en Velvet & Blade, un establecimiento que integra servicios de Barbería de Autor y Spa de Uñas.
El sistema permite gestionar el proceso de reserva de servicios, consultar disponibilidad de estaciones y profesionales, realizar seguimiento de citas y consultar el historial de atenciones.
 
----Descripcion del Proyecto----
 
Velvet & Blade requiere una solución móvil que permita organizar el flujo de atención de clientes y reducir la saturación en recepción.
La aplicación centraliza el proceso de agendamiento mediante una interfaz móvil intuitiva, permitiendo al usuario:
Iniciar sesión y gestionar su cuenta.
Registrarse como cliente o especialista.
Consultar los servicios disponibles.
Seleccionar una estación o profesional.
Consultar fechas y horarios disponibles.
Agendar servicios.
Consultar citas activas.
Revisar el historial de servicios.
Visualizar el estado de sus citas.
Recibir confirmaciones y alertas mediante componentes nativos.
 
----Objetivos----
 
- Objetivo general
Desarrollar un prototipo funcional de una aplicación móvil híbrida para la gestión de citas, servicios y estaciones de atención de Velvet & Blade.
- Objetivos específicos
 
* Diseñar una interfaz moderna, elegante y responsiva.
* Implementar navegación entre los principales flujos de usuario.
* Crear las pantallas requeridas utilizando componentes de Ionic.
* Gestionar visualmente los estados de las citas.
* Implementar selección de servicios, estaciones y horarios.
* Integrar capacidades nativas mediante Capacitor.
* Preparar el proyecto para su ejecución en Android y iOS.
